# Electric Vehicle (EV) Trends Data Analysis 

This project analyzes a dataset of Electric Vehicle (EV) trends to explore key market dynamics, geographical adoption patterns, and vehicle characteristics. The goal is to extract meaningful insights that describe the current state and future direction of the EV market.

---

## Key Analysis Areas

The project focuses on answering critical business and policy-relevant questions, including:


* **Vehicle Specifications and Popularity:** Analyzing trends in vehicle **'manufacturers'**, **'model'**, and technical specifications (e.g., type, electric range) to determine consumer preferences.
* **Market Segmentation:** Using the **'make'** column to categorize and visualize data for specific manufacturers, allowing for direct comparison of their market presence and characteristics.
* **Geographic Distribution and Density:** Mapping the concentration of EVs based on **Latitude and Longitude** to identify high-adoption regions.
---

This project is built entirely in Python and utilizes the following libraries:

| Category | Library | Purpose |
| :--- | :--- | :--- |

| **Data Visualization** | `matplotlib.pyplot` | Creating static charts and graphs for general trend analysis. |
